# Параметры всех конфигов проекта

Актуализировано 2026-10-13 по текущему рабочему дереву. Перечислены все листовые параметры каждого JSON-файла в `config/`, включая элементы массивов и значения `null`.

Машинные схемы находятся в [schemas](schemas/) и не входят в таблицы. Производные конфиги в `build/config/`, данные конкретного робота, Dockerfile и штатные настройки Unity/.NET также не являются файлами `config/`.

`config/shared/protocol/semantics.json` включён полностью: его значения задают контракт протокола; изменение требует согласованного изменения реализаций и проверки совместимости. Это не пользовательские переключатели безопасности.

Имя файла сохранено для существующих ссылок, но охват теперь включает EV3, Quest, Shared и Tooling. CSV удалён. Значения задаются только в исходных конфигах; таблица — справочная сводка.

## Проверка кода

Просмотрены host-команды tooling, поиск инструментов, runtime-загрузчики EV3/Quest, сетевые потребители, цикл управления и HUD Quest. Найденные настраиваемые host-таймауты ADB/SSH, установки/bootstrap и запуска Quest, SSH connection/keyscan и интервалы ожидания перенесены в `config/tooling/settings.json`. Имя override-переменной apksigner перенесено в Quest Android environment. Прежние значения по умолчанию сохранены.

Wire/IPC layout остаётся в схемах; криптографические требования и запреты приводов — в контрактах. Период 50-Hz control loop, bounded buffers, стандартные пути systemd/sysfs и layout HUD не сделаны свободными runtime-настройками. Фиксированная разводка и частично декларативные rate-поля EV3 по-прежнему отмечены в таблице.

Фиксированный protocol robot_id задан в EV3 runtime schema, а не в исходных конфигах. Вычисляемые qualification/scope/input-поля также не хранятся в исходных конфигах. Текущий генератор ещё связывает Diagnostic с network-only: разделение профиля сборки и режима запуска обсуждено, но не реализовано этой задачей.

## Проверка полноты

Рекурсивный обход 6 файлов сопоставлен с таблицами по файлу, пути и JSON-значению: 105 параметров без пропусков, лишних строк и повторов. Элементы массивов представлены отдельными строками с индексами. SHA-256 соответствует текущим байтам исходников.
