# PHANTOM

PHANTOM — система телемеханического управления манипулятором. Meta Quest 3 отслеживает
намерение пользователя и передаёт целевые положения; LEGO Mindstorms EV3 управляет
приводами и обеспечивает локальные ограничения безопасности.
