# PHANTOM

PHANTOM — система телемеханического управления манипулятором. Meta Quest 3 отслеживает
намерение пользователя и передаёт целевые положения; LEGO Mindstorms EV3 управляет
приводами и обеспечивает локальные ограничения безопасности.

Начните с [требований к продукту](docs/product-requirements.md) и
[системной архитектуры](docs/system-architecture.md). Владельцы остальных областей
и правила согласованности описаны в [правилах спецификации](docs/specification-governance.md).

Для работы с проектом используйте [разработку и развёртывание](docs/engineering.md),
[этапы реализации](docs/implementation-stages.md) и [текущий статус](docs/current-status.md).
Процедуры приёмки и связи требований с проверками находятся в [плане проверки](docs/test-plan.md).
